# Domain rules

The rules behind the terms in [GLOSSARY.md](../../GLOSSARY.md).

## Scope

ringmaster is a scaffold: today it has organizations, their members (`admin` and
`staff`), sign-in and the audit log. The organization and its first admin are created
through `/api/setup`; there is no public sign-up. The data model is
multi-organization.

The product it is meant to become is a catalog for Argentine small businesses:
clients and products. None of it is built yet. Each area gets a page here when its
rules are agreed, and its terms go in the glossary.
